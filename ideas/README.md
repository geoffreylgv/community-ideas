# Ideas

Add each proposal as a separate Markdown file in this directory. Before creating a new file, check whether a similar proposal already exists.

Use [`template.md`](template.md) as a starting point. You may write in English or French; both versions are not required.

Examples of topics include software projects, workshops, events, learning resources, inclusion initiatives, and improvements to community activities.

For contribution instructions, see [`../CONTRIBUTING.md`](../CONTRIBUTING.md). French version: [`README.fr.md`](README.fr.md).
