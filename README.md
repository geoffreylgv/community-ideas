# Community Ideas

A collaborative space to propose, discuss, and develop initiatives for our community.

**You do not need to know how to code to contribute.**

## About

Community Ideas helps community members share suggestions, propose open-source projects, and improve our activities. Proposals may include software projects, workshops, training sessions, events, inclusion initiatives, and improvements to community tools or processes.

## Goals

- Collect ideas and suggestions from community members.
- Identify projects and initiatives worth exploring.
- Encourage collaboration and open-source participation.
- Help turn useful ideas into actionable initiatives.

## How to contribute

1. Browse the existing proposals in [`ideas/`](ideas/).
2. Check whether a similar idea already exists.
3. Read [`CONTRIBUTING.md`](CONTRIBUTING.md).
4. Fork this repository and create a branch.
5. Add your proposal as a separate Markdown file in `ideas/`.
6. Open a Pull Request explaining your contribution.
7. Participate in feedback and improve your contribution when needed.

You can contribute in English or French. You do not have to provide both translations.

## Proposal format

Use the template in [`ideas/template.md`](ideas/template.md). Each proposal should explain the problem, the proposed idea, its expected impact, and a possible first step.

## Community guidelines

Be respectful and constructive. Search for similar proposals before submitting a new one. Do not publish private or confidential information. See [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
